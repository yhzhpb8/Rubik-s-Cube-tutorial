# 魔方复原教学器 · 零基础分步教程

一个**纯前端、零基础友好**的 3D 魔方复原教学网页。跟着 8 个阶段、19 个小步骤，从完全打乱一步步还原到六面同色；每个公式都带 3D 动画演示，重要色块会高亮提示，不必记背也能学会。

> 在线体验：把本仓库部署到任意静态托管（GitHub Pages / Vercel / Netlify 等）后，打开首页即可。也可以直接双击 `index.html` 在电脑浏览器离线使用。

---

## ✨ 功能特性

- 🧊 **真 3D 魔方**：基于 Three.js 实时渲染 26 个小方块，可拖动旋转、滚轮缩放，从任意角度看清每一步。
- 🪜 **八步分层教学**：从「公式基础」到「顶角归位」，由易到难，每步只教一个动作。
- 🎬 **公式动画演示**：点「播放」自动转动魔方演示公式，慢动作看清每一面怎么转。
- 🔦 **高亮提示**：当前步骤要动的块会高亮，不用自己费眼找。
- ⏮️⏭️ **自由导航**：上一步 / 下一步 / 阶段跳转 / 步骤列表，随时回看或跳过。
- 📱 **手机离线可用（PWA）**：添加到手机主屏幕后，断网也能打开使用。
- 📦 **零依赖、零后端**：不需要安装任何环境、不需要联网、不收集任何数据。

## 🗺️ 八步教学路线

| 阶段 | 名称 | 目标 | 步骤数 |
|---|---|---|---|
| 1 | 公式基础 | 认识 6 个面、12 种标准转法（R/U/F…） | 1 |
| 2 | 底部十字 | 白色十字归位（第一层棱） | 3 |
| 3 | 底部边角 | 第一层角块归位，完成底面 | 3 |
| 4 | 中间边角 | 第二层棱块归位 | 2 |
| 5 | 顶部十字 | 顶面出现黄色十字 | 3 |
| 6 | 顶部边角 | 黄色角块归位 | 4 |
| 7 | 顶棱归位 | 顶层棱块归位 | 2 |
| 8 | 顶角归位 | 魔方完全复原 | 1 |

> 共 **19 个步骤**，每个步骤都内置「初始状态 → 公式 → 判断标准 → 小贴士」，照着做即可。

## 🚀 快速开始

### 方式一：电脑直接打开（最简单）
双击 `index.html`，用 Chrome / Edge / Firefox 打开即可，无需任何配置。

### 方式二：本地起服务（便于手机同 Wi‑Fi 访问）
```bash
# 在项目目录执行（需已安装 Python）
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```
手机与电脑连同一 Wi‑Fi 时，访问电脑局域网 IP（如 `http://192.168.x.x:8080`）。

### 方式三：部署到 GitHub Pages（获得公开 https 网址 + 手机离线 App）
1. 新建一个 **Public** 仓库。
2. 把本目录**内容**（`index.html`、`three.min.js`、`manifest.webmanifest`、`sw.js`、`assets/`）上传到仓库**根目录**。
3. 额外建一个名为 `.nojekyll` 的空文件。
4. 仓库 **Settings → Pages**，Source 选分支、`/root`，保存。
5. 等 1～2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可。
6. 手机用 Safari 打开该 https 网址 → 分享 → **添加到主屏幕**，之后断网也能用。

## 🛠️ 技术说明

- **纯静态前端**：HTML + CSS + 原生 JavaScript，无框架、无构建步骤。
- **3D 渲染**：[Three.js](https://threejs.org/)（`three.min.js`，已随仓库提供）。
- **离线支持**：`manifest.webmanifest` + `sw.js` 实现 PWA 离线缓存；`assets/` 内为导航栏 logo 与各尺寸 favicon。
- **魔方数学模型**：内置 `Cube3D` 类，以四元数记录每个小块的位置与朝向，公式用标准记号（R/U/F/L/B/D 及其撇角与双转）。

## 📁 目录结构

```
CubeTutor（仓库根目录）
├── index.html            # 主页面（教学逻辑 + 3D 渲染 + UI）
├── three.min.js          # Three.js 3D 引擎
├── manifest.webmanifest  # PWA 清单（名称 / 图标 / 全屏）
├── sw.js                 # Service Worker（离线缓存）
├── serve.py              # 本地测试用静态服务器（可选，部署不需要）
└── assets/
    ├── logo-80.png           # 导航栏 logo
    ├── favicon.ico           # 浏览器标签页图标
    ├── favicon-16.png        # 小尺寸 tab
    ├── favicon-32.png        # 高清 tab
    └── apple-touch-icon.png  # iOS 主屏幕图标
```

## 📝 使用建议

- 第一次学时，建议从阶段 1 按顺序走，每步先「播放」看动画，再自己手动转一遍。
- 卡住时退回上一步看「初始状态」，确认自己的魔方和图上一致再继续。
- 手机端「添加到主屏幕」后体验最接近原生 App，且无广告、无追踪。
